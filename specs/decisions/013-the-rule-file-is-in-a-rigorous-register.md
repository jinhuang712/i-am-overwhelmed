# 013. The whole rule file is in a rigorous written register

Decided: 2026-11-18

---

## The problem

The rules ask the agent for a rigorous written register, and the file itself was written in plain, spoken words: "Don't cave", "Push back", "the main thing only". The owner holds that a rule file must be written in the register it asks for, since the agent copies the manner of its instructions. A scan found 73 such places outside the lines drafted that day.

---

## The choice

All 73 places were reworded at once, and 3 more that keep the file consistent. The file has no idiom, no figure of speech, no contraction and no "thing" where a term fits. Two blocks of the template got new names: `<push-backs>` is `<objections>`, and `<pick>` is `<recommendation>`. The rules ask for the same as before.

---

## Not chosen

3 other ways:

- **In batches, the template and the trees first**: the agent's pick, to watch the effect of each step.
- **Only the contractions and the vague nouns**: 16 places that change no sentence.
- **Leave the older rules as they were**: their wording was the owner's own and had evals behind it.

---

## Consequences

The wording of most rules is new, and past evals show that the wording decides whether a rule is followed. No eval has seen the new wording. The file leans toward the formal edge of the register, and it still has to keep clear of officialese.
