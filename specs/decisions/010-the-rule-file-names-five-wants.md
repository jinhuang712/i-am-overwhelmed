# 010. The rule file names the reader's five wants

Decided: 2026-11-18

---

## The problem

The rule file told the agent who the reader is and what to do, and never what the reader wants. Most of what the owner asked for on 2026-11-18 already had a rule, and the rule was not followed. Where no rule fits, the agent had only the reader's traits to go by.

---

## The choice

A part "What I Want" stands after About Me and names five wants: to trust what a reply says, to grasp the main point at a glance, attention on the right things, every line carrying something, and a discussion that moves fast. About Me holds only what the reader is.

---

## Not chosen

2 other ways:

- **The wants in the docs only**: the agent that writes the reply never reads the docs.
- **A want written as a line of About Me**: the owner turned it down, since such a line says what the agent should do.

---

## Consequences

The file is longer by one part. A want is a principle, and a principle has lost to a plain rule that stood next to it, so the rules stay.
